# SkillGig 💼

SkillGig is a modern job portal built with React that connects job seekers and recruiters through a clean, intuitive platform. Users can discover job opportunities, engage with the community, and apply for positions.

## Features

- Modern landing page
- Trending Jobs
- Community Feed
- Statistics Dashboard
- Responsive Navigation
- Footer
- Responsive UI (Work in Progress)

## Tech Stack

- React
- Vite
- Tailwind CSS
- React Router
- Git & GitHub
